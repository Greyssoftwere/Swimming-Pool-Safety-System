# Swimming Pool Safety System

An embedded system designed to monitor a swimming pool area and detect unauthorized entry or accidental falls. The project uses a microcontroller and an infrared motion sensor to provide early safety warnings.

## Features
* Active Perimeter Monitoring: Continuous scanning for motion around the pool edge.
* Instant Detection: Utilizes hardware interrupts for low-latency response times.
* IoT Ready: Built on the ESP32 platform, allowing for future Wi-Fi and Bluetooth notification setups.


## Components
* ESP32 development board
* PIR motion sensor
* Breadboard
* Jumper wires
